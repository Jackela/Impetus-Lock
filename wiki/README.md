# Impetus Lock 知识库

本库整理写作游戏设计、微信平台和 GitHub 开发实践的一手资料，便于后续方案回查和复核。

- [GitHub 开发范式](github-development.md) · 迭代 Issue、可复现任务、OpenSpec、人工评审和结果证据。
- [Rogue-like 玩法借鉴](roguelike-design.md) · 同题写作、能力组合和局间解锁，以及 bunkiten 的点选与自由输入参考。
- [微信小程序平台](wechat-platform.md) · 语音、隐私、分享和公开首发的资料及主体核验事项。
- [来源和更新记录](SOURCES.md) · 原始链接、固定版本、核对日期和变更摘要。

## 维护方法

1. 收录时先读原始材料，优先登记固定提交、发布版本或公告链接。动态网页记下核对日期。仓库内资料保留当前文件链接，引用历史结论时另记对应 Git 提交和路径。原始资料保存在原处。
2. 优先更新已有主题。在具体主张附近注明来源，写清哪些是原文事实、设计推论、项目取舍或待核事项。新证据与旧结论冲突时，记录具体差异、适用时间和受影响的页面。
3. 查询时从主题追溯来源，涉及当前范围或状态时再读项目文件。修订后核对入口可达、链接和版本锚点有效、主题无重复，并在来源页追加一条变更记录。
4. 收录公开上线后的反馈时，保留版本、入口、复现步骤和脱敏结果。用占位内容重述问题，剔除私人草稿、音频、用户标识、后台敏感字段和凭据。
