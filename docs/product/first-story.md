# 首局功能设计：那封寄给自己的信

玩家只用点选，也能决定怎么处理来信、用能力影响后续故事、写到一个可以收笔的地方。任何一轮都可以改用键盘或语音接着写。以下三回合用同一组行动对照普通锁句模式和高强度模式，正文和选项是走读示例。实际小程序应根据本局已经发生的事生成后文与锁句。

## 开场与首句锁句

没有作品卡的新玩家首次打开微信小程序，就看到《来信》和可编辑题句“十年后，你收到一封自己寄出的信”。同屏提供“翻看信封”“请女儿看笔迹”和“自己写”。前一个行动可以沿邮戳或信封寻线索，后一个把女儿引进这一幕，沿她实际辨认到的笔迹续写。朋友先读已分享版本，决定玩同题后从原开场独立开始。回访玩家在身份确认后可继续未完成的故事。

把“十年后”改为“搬家那天”会改动本局开头，回合数保持为零，直到成功写入一段实际续写。点击剧情行动即开始；若身份尚未确认，显示等待并在本人身份确认后自动续办。生成始终使用本次确认的题句和所选行动。先点后改或选择接管时，未生效的旧选择不再入稿；若先前结果未知，先查原回执。首段由模型实时生成，下面的段落仅供走读。

玩家点“翻看信封”。正文写到女儿等着和我去放风筝，那只风筝是楼下的老周昨天帮她补的。我把信封转到窗前，看了一眼邮戳。这个开场动作成功入稿后，两种模式都把下一句写进正文，并标明已锁。

> 邮戳上的日期，却是明天。

普通局在此处用一句短说明告诉玩家锁句会留在正文，可顺着它写，也可另选行动。选“请女儿看笔迹”的局以她和笔迹实际发生的情节生成锁句。高强度或允许不可恢复删除时，先展示该局规则并取得明确确认再开局。

## 首锁后的三个回合

### 第一回合：把信烧掉

> 信封先塌下去，里面的纸也烧透了。信里写了什么，我一个字都没看见。

两局中女儿都在厨房门口，亲眼看见了这一幕。以后谁也无法再拆这封信或检查原件，正文里仍记着我看过的日期。如果当初选的是“把信留下”，原件还在，玩家后来想拆开或仔细辨认邮戳，都有东西可查。两种决定不能靠一封内容相同的退件或副本合并成同一条去邮局的路。玩家仍可以主动追查，例如向家人打听那天有谁来过。

烧信入稿就是对第一句锁句的有效回应。第一次奖励出现，玩家选**旧人物回场**。页面回到剧情选项和“自己写”，等玩家决定下一步。

### 第二回合：去买早饭

两种模式都写我和女儿到了包子铺。老周也在那里买早饭，见我们拎着风筝，就用筷子指了指尾巴：“竹骨是我补的，这截布你问她。”买早饭是玩家选择的行动，刚选的“旧人物回场”让这个已经出现过的人自然走进这一幕。

**普通锁句模式。** 老周顺手抻平补过的风筝尾巴。正文出现一条由眼前情景生出来的新锁句。

> 风筝尾巴上系着她旧校服的一截蓝袖口。

**高强度模式。** 女儿原本在摸口袋里的纸。看见我袖口还有灰，她问：“要是我写的，你也会烧吗？”这次可以锁住烧信带来的一项后果。和普通锁句模式一样，新锁句在买早饭的行动里入稿。

> 女儿把原本要递给我的那张纸收回了口袋。

同一次烧信最多由系统主动带出这一项后果。玩家可以问她刚想给自己看什么，也可以接着去放风筝，把纸里的内容留作悬念。

两种模式里，老周在场都让玩家多一个可做的动作，例如“请老周教她看风向”。玩家也可以直接去公园。老周回场只带来这个选择，教看风向要等玩家点了才写进正文。

### 第三回合：不查信了，陪她放风筝

两种模式都把这个决定写成一段可以收尾的正文。例如我把线轴交给女儿，她一边往前跑，一边慢慢松线。普通模式里，可以写那截蓝袖口被风拉直。高强度模式里，女儿也可以干脆跑起来，回头喊我松手。她没再提口袋里的纸。玩家可以就此收笔。

上一回合如果写入了新锁句，这一段成功入稿后便是一次新的回应。想继续的玩家可以再选一次能力。再次选中回场能力会进化成**旧人物带回线索**。选定后，页面照常先回到剧情选项和“自己写”。玩家接下来点“坐下歇一会儿”，老周收摊后经过长椅，说：“她昨天来找我修风筝，说今天不能再让你拿风筝坏了当理由。”玩家这才有机会问她等了多久，也可以什么都不问。

## 局内能力怎么选、怎么用

**旧人物回场**在后续行动里安排已经出现过的人自然回来。进化后的**旧人物带回线索**还能让回场的人带来一条与已写情节相关的线索，例如老周知道女儿为什么执意补风筝。系统从本局已经出现的人和事中选取合适的人物与线索，玩家只需选这张能力卡。卡面应说明它会改变以后的出题，正文应能看出这一次是谁回来了、带来了什么。

**换个解释**让后文为锁句提出与已有事实相容的新读法。譬如同题另一次游玩，玩家选“把信留下”。后来翻看原件，才发现邮戳盖在一小块透明胶带上，可能是有人在别处做好了再贴上去的。普通锁句模式下，再次选中这张卡会让它进化。玩家此时可以采用这个解释，也可以留白，等故事长出其他线索。采用后，下一段沿所选解释发展，原锁句仍标为已锁。验收时可分别尝试用普通编辑改句和让普通 AI 改句，核对这两种操作都保留原文和锁状态。

**高强度模式中的进阶动作**在开局说明许可和使用条件。玩家在本局取得“换个解释”、使它进化且仍启用时，可以主动选“解锁原句”或“替换原句”，两个动作共用每局一次机会。解锁前显示目标原句及解锁后的效果，玩家确认后，这句便可按普通正文编辑。选择替换时，先展示原句、拟替换的文字和适用的恢复规则。譬如烧信后，界面可以预览用“窗玻璃反着光，我把模糊的邮戳看成了明天。”替换第一句锁句。玩家确认且操作成功后才消耗机会，新句默认重新锁定。两种动作都要承认已经发生的事，例如烧掉的信仍无法打开。应能从界面分别看出原句解锁、原句仍锁或新句重新锁定的结果。

两条能力也可以在一段里一起起作用。假设玩家主动继续查邮戳，前文见过的邮局柜员翻出当天的维修簿，指给玩家看：日期轮卡过一回。柜员的记录既是旧人物带回的线索，也为“日期可能盖错了”提供了依据。接下来可以问经手的人，也可以接受这个解释后回家。即使原信已经烧毁，这段也有独立的信息来源。

首发只提供这两种能力。有两项适用时二选一，也可以跳过。只有一项时同时提供这项和“跳过”。两种能力尚未都升到最高级、眼下又没有适用选项时，回应照常计，玩家可以直接继续。玩家始终可以收笔。已启用的相容能力会共同影响后续出题。两种能力都升到最高级后，后续新回应的奖励可用来停用一项、恢复一项或维持现状。已取得的能力和等级照常保留，变动从之后的行动起生效。已经写入的正文和锁不随之改写。刷新页面、恢复或重试同一回应均不能重复获得奖励，停用后再启用也不会补充已经用掉的次数。

剧情选项决定人物当下做什么，能力决定后续如何出题。选能力本身不增加回合。玩家下一步如果改用“自己写”，先保留这次提交的原文，能力适合接入时就在同一回合接着写，新增的锁句照常标出。这次行动只算一个回合。也可以在看见第一句锁句时就转向自由写，例如写“我把信塞回了抽屉，一会儿还得接她放学”，段落入稿同样算有效回应。能力在当前行动里缺少合适的出场机会时，可以等到后续行动。

## 收笔后发现新玩法

| 达成条件                                   | 开放内容                                         |
| ------------------------------------------ | ------------------------------------------------ |
| 首篇至少有一段有效续写并收笔               | 《古风探案》和高强度模式。未回应首锁也可以达成。 |
| 之后另一个局累计至少一次有效回应并收笔     | 个人模式和可恢复改写。                           |
| 之后再另开一局，累计至少两次有效回应并收笔 | 删除规则。启用不可恢复删除的规则仍须逐局确认。   |

《古风探案》的题句是“县衙还没升堂，案头已经摆好了一份结案书。”这局从案卷与本局人物建立事实。已经出场的书吏可以回来带来文书来源，已有锁句也可从案卷与证词得到另一种解释。来信、女儿、老周以及前一局取得的能力和事实不带进这一局。首发仍只有“旧人物回场”和“换个解释”两条能力。

## 接管写作和收笔

剧情选项旁常驻“自己写”。打开后，同一处可打字或按住说话。正常松手后自动发送。当前选的风格可以是逐字记录、保留口吻或轻度书面化。默认保留口吻，例如“我、我认识这只鸟……不，不可能”，可以整理起音卡顿，但应留下有意重复的“不，不可能”。三种风格都不能把“女儿”改成“妹妹”或擅自添加往事。作者可核对识别原文，识别或整理失败时能重试、用原文或改用键盘。

| 操作                 | 可观察的结果                                                                                                         |
| -------------------- | -------------------------------------------------------------------------------------------------------------------- |
| 收笔时有文字正在生成 | 暂停后续干预。让玩家处理正在生成或提交中的内容，确定要带走哪一版，再固定正文。晚到的回包不能改掉已经取走的作品。     |
| 编辑或带走私密作品   | 玩家在已收笔的作品中可以更改原锁句，可复制或导出 UTF-8 TXT。作品独立保存，挑战稿和该局已经结算的能力或进度照常保留。 |
| 朋友看作品并写同题   | 打开卡片先读已发布的只读正文和 AI 标识，再选择玩同题。朋友从原题和原初始规则组建新局，独立决定后续能力和结局。       |

## 从 bunkiten 借什么

bunkiten 的行动按钮、键入和语音都能提交玩家回合。引擎把行动或台词写成下一幕。自由输入偏离分支时，故事可以沿这个新决定发展。Impetus Lock 借用“有选项、也能走出去”，再用锁句和持续能力塑造不同局的规则。世界线管理、全章剧情树、立绘和桌面引擎均未纳入这份小程序设计。对应源码和适用边界见[研究记录](../../wiki/roguelike-design.md)。
