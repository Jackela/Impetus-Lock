# Change: 微信小程序选题、剧情点选与自由写

OpenSpec 第一阶段，待审批。

## Why

微信用户免注册选题开局，可以一路点选剧情行动，由系统根据选择续写，完成故事并获得规则认可的成长。想自己决定具体写法时，可随时接管并使用语音或键盘。小程序在后台确认微信身份，以便恢复本人草稿并隔离他人的私有稿件。

## What Changes

- 微信用户可从搜索或最近使用打开小程序，在首页选题开局，或从好友分享的作品卡另开同题局。全流程无需注册 Impetus Lock 账号，也无需提供手机号或邮箱。题面可被定位，独立邀请卡暂待决定。
- 首局默认提供剧情行动选项。玩家选定当下的情节方向，系统据此续写。剧情行动写成的有效新段与自由写入稿适用同一规则。能力选项改变后续玩法，由局规单独记录。规则服务按局规生成并标识锁句。
- 自由写可用键盘和按住说。正常松手按当前样式处理并自动入稿，默认保留口吻，另可用逐字或轻度书面化。支持查看和恢复该段识别原文。剧情选项旁常驻“自己写”，打开后同一处提供打字和按住说话；纯点选不申请麦克风也能完成首局。
- 剧情行动、键盘和语音的新段都按归属、稿件版本、锁和稳定输入标识提交。请求中断、重试、竞争写入与迟到结果均有对应处理。原声音频仅作临时转写，作品和分享使用各自规格允许的成稿内容。

## Impact

- `wechat-voice-entry` 规格涵盖小程序入口、选题、剧情点选与自由写。此分支基线只有 Web 客户端和 FastAPI 服务，小程序及相关能力均待实现。
- `add-story-challenge-rules` 定义有效续写、故事进程、能力与干预规则。普通和高强度模式选完能力都回到行动入口，后续呈现遵循故事局规则。`add-story-sharing` 定义作品及分享。完整首局和作品回流需联验这三个变更。
- 小程序入口单独建立身份和会话边界。现有 Web 邮箱账号、Cookie/CSRF、任务路由和历史数据继续按 [编辑器规格](../../specs/editor-agentic-ui/spec.md) 与 [任务规格](../../specs/task/spec.md) 工作。
- 选型建议和实际主体待查项见 [设计](design.md)。
