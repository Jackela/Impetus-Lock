## 1. 确认接入

- [ ] 1.1 记录提案审批和故事局、分享接口约定。用实际微信主体核对登录、插件许可、类目、隐私条款与数据处理条件，按设计选定语音服务，记录临时音频保存上限。
- [ ] 1.2 先写失败测试，覆盖微信身份隔离、Web 认证兼容、三种续写来源的去重、纯点选不请求麦克风、点选生成失败及接管、断网与过期会话、锁与版本冲突、永久删除后的游戏内恢复限制。

## 2. 实现

- [ ] 2.1 实现首页直接选题、剧情选项旁常驻的“自己写”及作品卡同题入口，以及独立技术会话和小程序稿件归属校验。
- [ ] 2.2 实现剧情行动选项、根据选择生成并入稿，以及自由写接管。接入规则判定、独立锁句及能力选项，覆盖生成失败、结果未知和切换输入方式。
- [ ] 2.3 实现键盘输入、录音、转写、按所选样式自动入稿、查看和恢复原文、失败处理和临时音频清理。三种续写均落实输入幂等与版本、锁校验，核对分享载荷和永久删除的资料边界。

## 3. 验证

- [ ] 3.1 在隔离数据库用两套真实微信身份和同设备切换复测草稿隔离、续期恢复、重复与迟到结果。运行项目质量门禁和既有 Web 登录、Cookie/CSRF、任务与锁回归。
