# Change: 微信故事挑战规则与成长

状态为设计，待批准实施。基线为 `6f23cdf1b387a4deefc5e8cf17a598371654642a`。

## Why

让作者从题面选择故事走向，由系统写出一段正文。作者也可以随时用语音或键盘接管创作。两种方式都能接住锁句、获得能力、完成故事并发现新题材和规则。

## What Changes

- 同题从相同的题面和初始规则独立开局。题面预填为可编辑的第一句。点选成文或自由写的新段成功入稿，均计为有效续写。普通和高强度模式使用同一节奏。以来信题为例，开局先翻看信封，第一段入稿后出现首锁。首锁后第一轮烧信、留信或自由写均可回应并获得能力选择。第二轮可随买早饭等行动呈现旧人物，并在段末出现第二锁。第三轮行动有效入稿、回应第二锁后，才可在本次能力选择中再次选择同类能力来进化。干预在当次输入和入稿处理结束后应用。
- 烧信入稿后，两种模式都尊重原件已被烧毁的事实。普通模式可以沿玩家的行动走向别处。高强度模式可以就同一次烧信主动呈现至多一次与玩家处境有关的后果，该后果有清楚的因果并可在正文中留痕。后续仍可转线，玩家主动重提时可以接着写。
- 首发能力是“旧人物回场”和“换个解释”。旧人物回场可进化为“旧人物带回线索”，由系统在符合上下文的行动中揭晓有独立来源的线索，并为玩家提供新行动。换个解释进化后，普通模式可由玩家选定解释继续发展，也可留下悬念，原锁照常保留。高强度模式还可在已进化且启用的条件下由玩家择时发动解锁或替换。两者每局共用一次成功机会，成功替换默认锁住新句，已发生的选择继续生效。
- 选能力只改变后续出题，下一行动开始呈现效果。自由写使当轮条件失效时，保留作者的新段和所选能力，等到适合的情节再呈现。能力可叠加，同类可进化。只有一项可用时显示该项和跳过，暂时无可用项时保留本次回应并继续。两条均进化到最高等级后，后续回应可关闭或恢复一条能力，也可保持当前组合。调整面向之后的行动，已经用掉的改锁机会不会重置。
- 普通编辑、常规 AI 干预和通用能力继续保护锁句。专用改锁的取消、生成失败和版本冲突不消耗成功机会。同一回执重放返回原结果，并发请求至多有一次成功变更。
- 首个有有效续写的已完成挑战开放新题材及相应的叙事能力，改写和删除规则随后逐步引入。全程点选也可完成作品和成长。
- 允许玩家使用已发现的规则设置触发条件、插入、改写、删除、锁定及原文可恢复性，并命名保存和再次开局。标准新手局只引入锁句。包含不可恢复删除的规则需要玩家在每次开局前确认，并说明产品内恢复的范围。
- 收笔由作者选择，可随时启动。从发起收笔起暂停发出和应用干预。公开发布和同题开局由 `add-story-sharing` 负责。自由输入的入稿和录音状态由 `add-wechat-voice-entry` 提供。

## Impact

- 新增规范 `story-challenge-rules`，覆盖微信故事挑战的规则、干预约束、成长和收笔。现行 `agentic-interventions` 和 `editor-agentic-ui` 仍描述既有 Web 合同。
- 预计涉及挑战局状态、干预服务、正文与锁的校验和持久化、用户规则库，以及微信端的写作和收笔界面。应保留旧 Web 干预 API 版本、请求响应、模式和旧稿兼容性。
- 锁执行涉及 P1。批准后先写失败用例，涉及锁核心的改动完成后由未参与实现的人员额外复核。Stage 1 仅供审阅，合并和发布各按项目授权办理。
