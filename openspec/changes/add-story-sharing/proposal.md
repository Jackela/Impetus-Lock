# Change: 故事收笔、保存与微信分享

2026-11-26 用户明确批准进入实施。完整作品流程、真机与双账号验收见任务清单。

## Why

作者可以只选剧情行动，由系统沿所选方向续写，也可以随时用语音或键盘接手。无论怎样成篇，作者都能随时收笔，把文字留下来继续编辑、带走或分享给朋友。

## What Changes

- 作者发起收笔时立即暂停新干预发出和落地，先处理或明确放弃待提交、结果未知的输入，再固定作品正文。作品包含已入稿的作者自写文字、系统按作者所选剧情行动写入的文字和可见锁句。作品可独立修改、保存、复制或导出 UTF-8 TXT。产品内查回被干预的原文继续按本局规则处理。
- 新玩家从小程序直接进入《来信》，回访可提供续写，好友从作品卡开同题局。首局免注册可完成收笔、保存、带走和主动分享。实际续写是否带来成长由局规判定，收笔、编辑作品、发布卡片和好友打开页面本身均不产生奖励。
- 作者确认本次可见的内容后生成微信作品卡。朋友凭卡片先读带 AI 标识的固定作品版本，再从相同题面和初始规则开自己的局。锁句、抽取和结果由各自的局决定。独立题目邀请卡是否提供待定。
- 编辑私密作品或另发新版本后，旧卡仍展示已分享版本，直至作者明确撤回。撤回后产品停止提供该卡片的正文和同题入口。已独立开始的局继续运行，已复制或缓存的外部内容无法追溯撤回。
- 未解锁高级规则的朋友可在有效卡片发起的同题局使用该初始规则，权限限于本局。开局授权由挑战规则统一处理。高强度或允许不可恢复删除时，每局开始前须明确接受。拒绝者可返回，也可主动另开明确标明为普通题的新局。

## Impact

- 新增 `story-sharing` 能力，覆盖收笔、作品、快照和由作品卡派生的新局。`add-wechat-voice-entry` 负责微信入口、免注册会话、剧情点选和自由写的输入交接。`add-story-challenge-rules` 负责在局内应用剧情行动结果，并管理挑战规则、开局授权及成长判定。实施应在对应依赖可用后按三份提案的接口连通。
- 涉及微信界面、作品持久化和分享读取接口、挑战启动交接。现有 Task API 继续以登录账户归属和乐观版本处理草稿与干预历史，微信体验使用自己的入口，账户工作区原有认证边界继续有效。参见 [task](../../specs/task/spec.md)、[editor-agentic-ui](../../specs/editor-agentic-ui/spec.md)。
- 微信卡片采用一次性正文快照，可转发。读者只能看到确认发布的标题（如有）、正文、AI 标识及同题公开信息。原声、内部挑战稿、干预历史和账户信息不属于公开内容。
- 实时协作仍按独立待审提案处理。[实时协作待审提案](../2026-11-09-collaboration-scope-decision/proposal.md)
