# 故事收笔、保存与微信分享设计

## 现有约束

现有账户工作区由 `AuthenticatedEntry` 确认服务器身份后挂载；`TaskService` 按账户读取任务，校验写入版本，并在读历史前验证归属。编辑器目前支持文档级 Markdown/PDF 下载，账户导出另走受保护的分页校验流程。新作品可复用适用的文字导出能力，先从作品正文生成导出内容。挑战 Task 及账户归档保留原有数据合同。[账户入口](../../../client/src/AuthenticatedEntry.tsx) · [任务服务](../../../server/server/application/services/task_service.py) · [文档导出](../../../client/src/services/exportService.ts) · [账户导出](../../../client/src/hooks/useAccountExport.ts)

## 收笔与作品归属

作者发起收笔后，挑战立即暂停发出和应用干预。正在录音、语音或键盘文字待提交，以及剧情点选后生成或入稿结果未知，均须先核对已生效的结果，让作者处理或明确放弃仍待处理的输入，然后固定正文版本。正常点选生成和正常松手入稿进入各自的自动流程。收笔只处理尚未完成或结果未知的操作。

以收笔时已生效、按本局规则可交给作者的完整故事正文生成独立作品。纯点选可成篇。作品保留系统根据作者所选行动成功写入的文字、作者用语音或键盘写入的正文，以及仍可见的锁句。锁标记和内部元数据不进入作品。晚到的干预或已放弃的输入不得改写冻结正文。按局去重收笔操作，后续修改私密作品也不触发挑战干预。若保存失败，界面保留收笔正文，让作者重试、直接复制或导出 UTF-8 TXT。空局仍可结束，作品生成以有可交付正文为前提。

作品归属沿用微信入口的已确认小程序身份。这一免注册身份与现有 Web 账户各自独立，用户可在小程序身份对应的保存范围内再次打开并继续编辑。保存前向作者说明实际可恢复范围。切换身份不得静默转移作品或覆盖其他稿件。私密作品的读写及卡片的发布和撤回均按作者归属检查，异步完成还须检查原身份与操作目标。

私密作品保存以正在编辑的作品版本为条件，冲突时保留作者当前修改和已保存版本。对于生成作品、发布或从卡片开局，使用同一操作标识核对已提交结果，网络超时可安全重试。若本轮保存状态未知，界面按未知处理，允许作者核对与带走当下正文。规则服务判定并结算挑战局内的续写成长。收笔、编辑作品和分享操作本身均不触发或重复发放成长。

## 卡片与同题开局

作者先预览即将公开的标题、正文、AI 标识和同题信息，明确发布才创建独立的只读快照标识。读者打开卡片先读公开快照，再决定是否同题开局。题面可定位到相应挑战，独立题目邀请卡是否提供待定。公开读取按允许字段返回内容，使用与作品和挑战私有标识分开的不可枚举分享标识。访问凭卡片建立，持有转发卡片的人也可读取。卡片可见摘要优先使用通用标题，正文经产品页面读取，降低微信预览缓存暴露正文的范围。产品不提供公开列表或索引入口，不把卡片访问转为对作者挑战稿的授权。

作品编辑或另发新版本时，旧快照继续展示原内容。作者如需替换已分享的版本，可单独撤回旧卡，再分享新的版本。撤回在服务端停止后续正文读取及派生开局，链接显示不可用。收回的边界在预览和撤回时提示，接收方已看过、复制、截图或由微信保留的副本可能继续存在。

公开快照关联 `add-story-challenge-rules` 提供的 `challenge_id`。新局启动时，由服务端校验卡片仍有效，再根据原 `challenge_id` 解析固定题面和初始规则版本。题面是新局预填的可编辑首句。好友的挑战从该初始状态创建独立身份，作者对首句的编辑、后续正文、锁句、抽取次数与结果、能力和成长均不交接。高级规则权限限于本局，开局授权委托给规则服务。高强度和不可恢复删除由规则服务按当前固定版本在每局开局前取得明确同意。若该版本无法执行或卡片已撤回，明确显示无法开启同题局，普通题需要单独选择。已完成创建的局不随原卡片后续撤回而变化。

## 依赖和验收

- `add-wechat-voice-entry` 交付后台确认的小程序身份、首页入口、微信端剧情点选和自由写操作，并提供稳定的输入标识与提交交接。正常松手即发送，识别文字按所选风格整理并成功入稿后，交给局规处理。只有入稿失败、目标发生冲突等例外才需要作者处理。原始音频、未提交的识别稿和语音恢复记录不进入作品、导出、卡片或分享服务的持久化路径。录音传输和清理由语音提案定义。
- `add-story-challenge-rules` 交付固定题面与初始规则引用、剧情行动入稿结果、开局授权、局内原文可见规则、收笔状态及成长判定。纯点选可以成篇并按规则成长。作者可随时用语音或键盘接管。被动收到锁句和输入尚未入稿均由局规排除在成长之外。作品只接收规则允许交付的当前正文。
- 作品和卡片可按能力独立实现与验证。新增持久化或 API 时，使用相应隔离数据库校验迁移与回退，并验证原账户流程。微信入口、分享卡片和权限必须在微信真机验证，浏览器或模拟数据用于覆盖逻辑回归。
