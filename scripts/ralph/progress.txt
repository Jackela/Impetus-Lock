- **Verification**:

  - The codebase already had `pool` configuration using `VITEST_POOL` environment variable
  - Added `poolOptions` to configure worker behavior for both pool types (threads and forks)
  - Setting `single: true` runs tests in a single worker process, avoiding Windows Git Bash fork issues
  - The `single-thread` configuration is safer on Windows but may slow down parallel test execution
  - This is a trade-off between stability (avoiding hanging processes) and speed (parallel execution)
