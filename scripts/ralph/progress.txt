## Codebase Patterns
- ESLint config uses modern `globalIgnores` function from `eslint/config` (not deprecated `ignore` array)
- Client tests use Vitest with custom wrapper script at `scripts/run-vitest.mjs`
- Frontend quality gates: lint (ESLint), type-check (tsc), test (Vitest)
- Backend quality gates: lint (Ruff), type-check (mypy), test (pytest)
- Article I (Simplicity): Use framework-native features over external libraries (e.g., native React hooks instead of React Query)
- **Exception**: React Query (v7.22.1) is now available for data fetching hooks (useQuery, useMutation)
- When adding new API endpoints: update TaskRepository protocol, both implementations, and routes
- React Query hooks need QueryClient wrapper (already configured in main.tsx)
- When testing React Query hooks: use QueryClient wrapper from `@tanstack/react-query`
- React Query v7: useMutation returns `isPending` internally, expose as `isLoading` for consistency
- React Query v7: State updates are asynchronous, use `waitFor` in tests for async state assertions
- Test files with JSX must use .tsx extension (not .ts) for proper parsing
